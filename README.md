# 🔥 Hellfire Club – Chat App

A real-time chat application inspired by the **Hellfire Club** aesthetic.  
Built for fast, secure, and smooth conversations with a dark-themed UI.

---

## 🚀 Features

- 🔐 User authentication
- 💬 Real-time messaging
- 🟢 Online / offline status
- 👥 One-to-one & group chat
- 🌙 Dark themed Hellfire-style UI
- 📱 Responsive design
- 🔔 Message notifications

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/rimondutta/Hellfire-club.git
cd hellfire-club

```

```bash
# frontend

cd frontend
npm install

# frontend run command
npm run dev

# backend

cd backend
npm install


# backend run command

npx nodemon

```

# env example

